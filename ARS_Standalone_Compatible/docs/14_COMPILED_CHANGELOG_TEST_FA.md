# تغییرات و وضعیت تست: نسخه C++ Config

**مبنای تغییر**: ZIP `ARS_Standalone_TCP_UDP_NoToken_INI_Qt67(1).zip` که کاربر فرستاده است. پروژه سناریومحورِ بسته دیگر مبنا نیست.

## انجام‌شده در سورس

- فایل `server/config/server.ini` و تمام INIهای Fixture حذف شدند.
- Stage/Install INI از CMake حذف شد؛ خروجی Release به تنظیمات زمان اجرا وابسته نیست.
- `Startup`, `Server`, `HotColdStore`, `HotColdWorker`, `PostgresStore` از یک Singleton فقط‌خواندنی استفاده می‌کنند.
- مسیر `--config` و متغیر `ARS_CONFIG` از خود سرور حذف شد.
- TCP/UDP، پیام `hello` و دستورات مشترک، آرشیو/بازگشت، Live و جست‌وجو در سورس نگه داشته شدند.
- یک پروفایل کامپایل‌شده LAB ایزوله با CMake اضافه شد.
- چهار اسکریپت مدیریتی بدون Config file به ورودی صریح یا Prompt تغییر یافتند.

## اعتبارسنجی

تست‌های سورس و Syntax اسکریپت‌ها قابل اجرا هستند. **Qt 6.7 SDK و سرویس واقعی Redis/PostgreSQL در این محیط موجود نیستند؛ به همین دلیل Build و Integration واقعی هنوز اجرا و تأیید نشده‌اند.** تست‌های قدیمی که به `--config` وابسته بودند در `tests/archived_ini_ported/` حفظ شده‌اند و در این نسخه اجرا نمی‌شوند؛ تست‌های جدید از `ARS_LAB_PROFILE` استفاده می‌کنند. ادعای پوشش کامل ۲۵ سناریوی مرجع در این نسخه وجود ندارد. گزارش‌های موفقیت قدیمی را نمی‌توان به این نسخه نسبت داد.

برای اعتبارسنجی واقعی، روی Ubuntu دارای Qt 6.7 و سرویس‌های آزمایشی، دستورهای فایل `docs/13_COMPILED_CONFIG_FA.md` را اجرا کن و نتایج `--check` و `tcp-test` را بررسی کن.
